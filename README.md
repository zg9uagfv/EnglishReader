# EnglishReader

一个使用 SwiftUI 和系统语音合成制作的英文文章朗读应用，同时支持 iPad 与 macOS。

## 功能

- 直接输入或粘贴英文文章
- 导入 UTF-8/ASCII 编码的 `.txt` 文件
- 美式英语与英式英语发音
- 连续调节朗读速度
- 开始、暂停、继续、停止及重新朗读
- 点词朗读，并显示音标、英英释义和英汉释义
- 自动整理粘贴文本的空格、换行与英文标点，并按句子排版
- 阅读字体、字号设置；单击单词重读，双击（iPad 上双击触碰）切换高亮
- 可选择设备已安装的英语声音；点读优先使用在线词典标准录音，离线时回退到系统语音
- 朗读时实时高亮当前单词，并自动滚动保持当前单词可见
- 儿童模式为常见功能词应用上下文弱读，避免将冠词 `a` 读成字母名
- 编辑与点词查询合并为同一文章区域，完成编辑后可直接点击任意单词
- 主窗口提供偏好设置入口，集中管理 TTS、儿童模式、字体与字号

> 点词查询使用在线词典与翻译服务，需要设备联网；查询结果会在本次运行期间缓存。

## 运行

用 Xcode 打开 `EnglishReader.xcodeproj`，选择 Mac 或 iPad 模拟器后运行。
